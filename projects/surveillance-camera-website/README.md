# VigilEye — موقع كاميرات مراقبة تجريبي

موقع بواجهتين (عربي RTL / إنجليزي LTR) لشركة كاميرات مراقبة وهمية، مع لوحة إدارة محمية برمز دخول تقدر منها تضيف/تعدّل/تحذف المنتجات — والتعديلات تنحفظ على السيرفر وتظهر لكل زوار الموقع، مو بس عندك.

## التشغيل

```bash
node server.js
```

ثم افتح: **http://localhost:3000**

ما يحتاج `npm install` — السيرفر مكتوب بدون أي مكتبات خارجية (Node فقط).

## لوحة الإدارة

- افتح الموقع واضغط على أيقونة ⚙ بأسفل الصفحة.
- رمز الدخول الافتراضي: **2580**
- لتغييره:
  - إما عدّل القيمة `ADMIN_PIN` بأول ملف `server.js`، أو
  - شغّل السيرفر بمتغيّر بيئة بدون تعديل الكود:
    ```bash
    ADMIN_PIN=1234 node server.js
    ```

من داخل لوحة الإدارة تقدر: تضيف منتج جديد، تعدّل أي منتج (الاسم والوصف بالعربي والإنجليزي، السعر، شكل الكاميرا، المواصفات، الشارة)، تحذف منتج، أو "تستعيد القائمة الافتراضية".

## كيف تنحفظ البيانات

كل التعديلات تنكتب بملف `data/products.json` (يتكوّن تلقائياً أول تشغيل). هذا الملف هو "قاعدة البيانات" — بسيط ومباشر، ويكفي تماماً لموقع تجريبي بحجم كذا. طالما نفس السيرفر شغّال، أي شخص يفتح الرابط يشوف نفس المنتجات بعد أي تعديل.

> ملاحظة: جلسات تسجيل الدخول (الأدمن) محفوظة بذاكرة السيرفر فقط — إعادة تشغيل السيرفر تسجّل خروج الجميع، وهذا مقبول لموقع تجريبي بحجم كذا.

## نشر الموقع على الإنترنت (اختياري)

هذا سيرفر Node عادي، تقدر تستضيفه على أي مزوّد يدعم Node.js (Render، Railway، VPS عادي...). فقط ارفع مجلد المشروع كامل وشغّل `node server.js` (أو `npm start`)، مع التأكد إن مجلد `data/` قابل للكتابة على السيرفر المستضيف.

## بدون سيرفر (نسخة احتياطية)

ملف `static-demo.html` هو النسخة القديمة اللي ما تحتاج سيرفر إطلاقاً (كل شي محلي بالمتصفح عبر localStorage) — تقدر تفتحه مباشرة بدبل كليك، لكن تعديلات الإدارة فيه تضل محصورة بجهازك ومتصفحك فقط، ما تنعكس على زوار ثانين. النسخة الحيّة الموصى بها هي `server.js` + `public/index.html`.

## البنية

```
surveillance-camera-website/
├── server.js            السيرفر (Node، بدون مكتبات خارجية)
├── package.json
├── public/
│   └── index.html       الواجهة (نفس التصميم، تتكلم مع السيرفر عبر /api)
├── data/
│   └── products.json    "قاعدة البيانات" — تتكوّن تلقائياً، غير متتبعة بـ git
└── static-demo.html     نسخة احتياطية بدون سيرفر (localStorage فقط)
```
