# HASNET — نسخة جاهزة للنشر على Netlify

هذي نسخة من موقع HASNET مجهزة تنشرها على Netlify وتصير شغالة بلنك حقيقي تقدر ترسله لأي زبون، مع لوحة إدارة (إضافة/تعديل/حذف منتجات) تنحفظ تعديلاتها لكل الزوار — بدون سيرفر تديره أنت بنفسك.

## كيف تشتغل التخزين والحماية

- **البيانات**: تنحفظ بـ [Netlify Blobs](https://docs.netlify.com/build/data-and-storage/netlify-blobs/) — تخزين حقيقي تابع لموقعك على Netlify، يبقى دائم بين كل الزيارات.
- **الإدارة**: محمية برمز PIN حقيقي يتحقق منه الكود اللي يشتغل على السيرفر (Netlify Functions) — مو مجرد كود بالمتصفح يقدر أي حد يتلاعب فيه.

## خطوات النشر

### 1. جهّز حساب Netlify
سوّي حساب مجاني على [netlify.com](https://netlify.com) إذا ما عندك.

### 2. انشر المشروع
**الطريقة الأسهل (سطر أوامر):**
```bash
cd netlify-deploy
npm install -g netlify-cli   # مرة وحدة بس
npm install
netlify login
netlify deploy --prod
```
راح يسألك تربطه بموقع جديد على حسابك — وافق، وانتظر لين يخلص. بآخر السطر بيطلعلك رابط الموقع الحي.

> ⚠️ **مهم جداً**: لا تستخدم السحب والإفلات (Drag & Drop) على [app.netlify.com/drop](https://app.netlify.com/drop) — هذي الطريقة تنشر الملفات الثابتة بس ومو راح تشغّل لوحة الإدارة (Functions) ولا التخزين (Blobs). استخدم `netlify deploy` من سطر الأوامر، أو اربط المشروع بمستودع GitHub (الخيار الثاني تحت).

**الطريقة البديلة (عبر GitHub):**
1. ارفع هذا المجلد (`netlify-deploy`) لمستودع GitHub.
2. من لوحة Netlify: **Add new site → Import an existing project** واختر المستودع.
3. Netlify راح يكتشف `netlify.toml` تلقائياً ويعرف وين الملفات ووين الـ Functions.
4. اضغط Deploy.

### 3. غيّر رمز الدخول (مهم قبل ما ترسل الرابط لأي زبون)
من لوحة تحكم موقعك على Netlify:
**Site configuration → Environment variables** وضيف:
- `ADMIN_PIN` = الرمز اللي تبي تستخدمه (بدل الرمز الافتراضي 2580)
- `ADMIN_SECRET` = أي نص عشوائي طويل (يستخدم لتوقيع جلسة الدخول — خله سري وما تشاركه)

بعد ما تضيفهم، اعمل **Deploy** مرة ثانية (Trigger deploy) عشان يطبّق المتغيرات الجديدة.

## طريقة الاستخدام

- افتح الرابط اللي عطاك ياه Netlify (أو الدومين المخصص إذا ربطته).
- اضغط أيقونة ⚙ بأسفل الصفحة، أدخل رمز الدخول (`ADMIN_PIN` اللي حطيته).
- ضيف/عدّل/احذف المنتجات براحتك — كل تعديل يظهر فوراً لأي شخص يفتح نفس الرابط.
- ارسل الرابط للزبائن — يشوفون كل شي، بدون ما يقدرون يعدّلون (ما عندهم الرمز، وحتى لو عرفوه، الحفظ الحقيقي محمي بالسيرفر).

## البنية

```
netlify-deploy/
├── netlify.toml                    إعدادات النشر والتوجيه (/api/* → الـ Functions)
├── package.json                    يحتاج حزمة @netlify/blobs بس
├── public/
│   ├── index.html                  الواجهة (نفس تصميم الموقع، تتكلم مع /api/*)
│   ├── robots.txt                  يسمح لمحركات البحث (كوكل...) بفهرسة الموقع
│   └── sitemap.xml                 يخبر كوكل برابط الموقع مباشرة
└── netlify/functions/
    ├── shared.js                   المنطق المشترك: التحقق من الرمز، القراءة/الكتابة بـ Blobs
    ├── products.js                 GET/POST/PUT/DELETE /api/products[/:id]
    └── admin.js                    /api/admin/login, /logout, /status
```

## إذا الموقع طلع "تعذّر الوصول لوظائف الحفظ"

هذا يعني الـ Functions ما اشتغلت — الاحتمال الأكبر إنك نشرت بالسحب والإفلات بدل `netlify deploy`. الموقع نفسه بيضل شغال ويعرض المنتجات (نسخة افتراضية مدمجة بالكود) حتى لو صار هذا، بس أي حفظ من لوحة الإدارة ما راح يشتغل لين تنشره بالطريقة الصح.

## ليش الموقع ما يطلع بالبحث بكوكل؟

- **أول شرط: لازم يكون عندك رابط حي فعلاً.** لو لسه ما سويت `netlify deploy --prod` (أو نشر عبر GitHub)، الموقع موجود بس على جهازك، وما يقدر كوكل يشوف شي ماله رابط عام على الإنترنت.
- **بعد ما ينشر، كوكل ما يفهرسه فوراً.** عادة ياخذ من كم يوم لين أسابيع. تقدر تسرّعها بإنك تسجل الموقع بـ [Google Search Console](https://search.google.com/search-console) (مجاني) وتطلب فهرسته يدوياً (Request Indexing) بعد ما تضيف الرابط.
- **الموقع هسه فيه أساسيات SEO** (وصف الصفحة `meta description`، كلمات مفتاحية، Open Graph لمعاينة أفضل لما ينرسل بواتساب/فيسبوك) — انضافت للـ HTML عشان تساعد كوكل يفهم محتوى الموقع أسرع.
- الموقع هسه عنده رابط أساسي (`canonical`) و`sitemap.xml` يشيرون بالضبط لـ `https://hasnet-cctv.netlify.app/` — كل الي عليك هسه سجل الموقع بـ Google Search Console واطلب الفهرسة عشان تسرّع الظهور.
